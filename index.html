SUBMISSION MATERIAL

Algorithms

01

Add Student

  1. Create a new node using malloc().
  2. Read registration number, name and marks.
  3. Set next = NULL.
  4. If the list is empty, make it the head.
  5. Otherwise traverse to the last node and link the new node.
02

Search Student

  1. Start from the head node.
  2. Compare each node's registration number.
  3. If matched, display the record.
  4. Move to next until the list ends.
  5. If no match is found, report not found.
03

Delete Student

  1. Traverse while keeping current and previous nodes.
  2. Find the node with the given registration number.
  3. Change the previous node's next pointer.
  4. If deleting the first node, update head.
  5. Free the deleted node.
04

Display Records

  1. Start at head.
  2. Visit each node sequentially.
  3. Print registration number, name and marks.
  4. Follow the next pointer.
  5. Stop when the pointer becomes NULL.
C IMPLEMENTATION

Source Code

#include <stdio.h>
#include <stdlib.h>

struct Student {
    int regNo;
    char name[50];
    float marks;
    struct Student *next;
};

struct Student *head = NULL;

void addStudent() {
    struct Student *newNode = malloc(sizeof(struct Student));

    printf("Enter Registration Number: ");
    scanf("%d", &newNode->regNo);

    printf("Enter Name: ");
    scanf(" %[^\n]", newNode->name);

    printf("Enter Marks: ");
    scanf("%f", &newNode->marks);

    newNode->next = NULL;

    if (head == NULL)
        head = newNode;
    else {
        struct Student *temp = head;
        while (temp->next != NULL)
            temp = temp->next;
        temp->next = newNode;
    }

    printf("Student record added successfully!\n");
}

void searchStudent() {
    int regNo;
    printf("Enter Registration Number to search: ");
    scanf("%d", ®No);

    struct Student *temp = head;
    while (temp != NULL) {
        if (temp->regNo == regNo) {
            printf("Student Found!\n");
            printf("Registration Number: %d\n", temp->regNo);
            printf("Name: %s\n", temp->name);
            printf("Marks: %.2f\n", temp->marks);
            return;
        }
        temp = temp->next;
    }
    printf("Student record not found.\n");
}

void deleteStudent() {
    int regNo;
    printf("Enter Registration Number to delete: ");
    scanf("%d", ®No);

    struct Student *temp = head, *prev = NULL;

    while (temp != NULL && temp->regNo != regNo) {
        prev = temp;
        temp = temp->next;
    }

    if (temp == NULL) {
        printf("Student record not found.\n");
        return;
    }

    if (prev == NULL)
        head = temp->next;
    else
        prev->next = temp->next;

    free(temp);
    printf("Student record deleted successfully!\n");
}

void displayStudents() {
    struct Student *temp = head;

    if (head == NULL) {
        printf("No student records available.\n");
        return;
    }

    while (temp != NULL) {
        printf("Reg No: %d | Name: %s | Marks: %.2f\n",
               temp->regNo, temp->name, temp->marks);
        temp = temp->next;
    }
}

int main() {
    int choice;

    while (1) {
        printf("\n===== Student Record Management System =====\n");
        printf("1. Add Student\n2. Search Student\n3. Delete Student\n");
        printf("4. Display Students\n5. Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1: addStudent(); break;
            case 2: searchStudent(); break;
            case 3: deleteStudent(); break;
            case 4: displayStudents(); break;
            case 5: exit(0);
            default: printf("Invalid choice! Try again.\n");
        }
    }
    return 0;
}

Short Demonstration & Explanation

What is a singly linked list?

A linear data structure where every node stores data and a pointer to the next node.

Why use it here?

Student records can be added or deleted dynamically without requiring a fixed-size array.

What is a node?

Each node contains registration number, name, marks and a pointer to the next student.

Complexity

Add at end: O(n) · Search: O(n) · Delete: O(n) · Display: O(n).
